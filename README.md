# AKRAM LIFE OS V1

PWA personnelle pour organiser Football (NRZ), travail, études, tâches et récupération.

## Mise en ligne sur GitHub Pages depuis iPhone
1. Créer un dépôt GitHub, par exemple `akram-life-os`.
2. Ouvrir le dépôt > Add file > Upload files.
3. Envoyer `index.html`, `manifest.webmanifest` et `sw.js`.
4. Settings > Pages > Deploy from a branch > `main` > `/root`.
5. Ouvrir l'adresse GitHub Pages dans Safari.
6. Partager > Ajouter à l'écran d'accueil.

Les données V1 sont stockées localement dans le navigateur. Utilise "Exporter JSON" régulièrement.
